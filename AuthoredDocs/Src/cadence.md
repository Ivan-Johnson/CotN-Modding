# Cadence

For players. What Cadence starts a single-zone run with.
Other characters: [dove.md](./dove.md). An all-zones run starts differently:
[all-zones-mode.md](./all-zones-mode.md).

* Cadence starts with 12 health.
* The inventory holds `Bomb`, `WeaponDagger` and `ShovelBasic`, plus
  `AddchestBlack`, `AddchestRed`, `AddchestWhite`, `CoinsX15` and `CoinsX2`.
  The last five sit in the `innate` slot and are not in Cadence's normal
  starting items. Their names say what they are: "+1 Black Chest Per Run",
  "+1 Red Chest Per Run", "+1 Purple Chest Per Run" (`AddchestWhite`), "Coin
  Multiplier +0.5" and "Coin Multiplier +1". The chest items set a run flag
  (`addChestBlack` and so on). Each coin item adds 0.5 to the coin multiplier, so they raise
  gold per kill ([coin-multiplier.md](./coin-multiplier.md)).
* The levels are random; see [stairs-and-levels.md](./stairs-and-levels.md).
